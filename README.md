# 🎯 Guess the Number

A simple interactive game where players try to guess a randomly generated number using higher-or-lower hints.

## ✨ Features

* Random number generation
* Higher/lower hints
* Attempt counter
* Previous guesses
* Replay option
* Simple and user-friendly interface

## 🛠️ Technologies

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
3. Start guessing!

## 🎮 How to Play

Enter a number and submit your guess. The game will tell you whether the secret number is higher or lower. Keep guessing until you find it.
